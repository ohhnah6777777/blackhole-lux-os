# Interactive Blackhole OS Apps

## Files
- Replace the static folder grid with a local in-memory file system containing Documents, Downloads, Pictures, and Games.
- Add clickable folder navigation with a live breadcrumb trail and back navigation.
- Add controls to create text files and delete selected items.
- Open text files in an editable Notepad dialog and save changes back into the file system.

## Settings
- Move appearance preferences into shared desktop state.
- Add functional dark/light appearance selection that updates the desktop and panels immediately.
- Add a wallpaper selector with distinct monochrome thumbnails and live desktop updates.
- Add a window corner-radius slider that updates every OS window dynamically.

## Interaction and validation
- Give controls clear selected, hover, disabled, and focus states.
- Verify file navigation, creation, deletion, editing, appearance changes, wallpaper changes, and window styling in the preview.
